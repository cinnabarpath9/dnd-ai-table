## 具体改动

1. **日志纸页**
   - `#log` 宽 860px 居中，纸色背景、内阴影、纸纹；
   - DM/PC/私有/引擎/错误分色，引擎行缩进+浅底；
   - DM 正文行高 1.9，移动端降到 1.78。

2. **大厅预设卡**
   - 5 张卡变成可点的卡面：姓名、职业/种族、HP、真人/同伴标记；
   - 选中的卡有“✓ 已选”和金色描边；
   - 只允许选满本桌人数；第一张给真人位，观战全给 AI；
   - “自定义卡 / 高级开桌”收进 `<details>`，减少首屏表单。

3. **地图**
   - 地图弹窗宽度最高 1180px、高度 88vh；
   - 六边格 SVG 填满可用高度；
   - 战斗层仍 5 尺方格。

4. **移动端**
   - 390×844 无横向滚动；
   - 日志纸页单栏；
   - 预设卡两列。

## 边界

- 全部仍内联在 `PAGE_HTML`，没有拆成组件/构建链；
- 颜色/字体只用系统字体栈，不依赖网络；
- 截图是 Chrome 1400×1000 / 390×844；Safari/Firefox/Narrator 未签；
- 纸页观感是视觉层，规则/状态/存档逻辑没改。
