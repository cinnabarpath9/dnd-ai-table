# 50 观战 / 托管 / BGM

> 三件事：**全 AI 观战（测试模式）**、**托管（AI 替你打，可接管）**、
> **BGM（浏览器合成，无外部音频文件）**。入口在网页顶栏。
> 座位/提示词见 [10](10-机制事实.md) §5，提示词见 [49](49-常驻提示词.md)。

## 1. 三种模式

| 模式 | 谁在答 | 页面 | 花费 |
|---|---|---|---|
| 真人（normal） | 你的角色等你点选项；其余 3 PC + DM + planner 是模型 | 输入框/技能栏 | 假模型 0；`--real` 按调用计 |
| 托管（hosted） | 4 个 PC 都由模型答；你的座位装了一个"代打"回调 | 隐藏输入框，显示「托管中」，可点**接管** | 同上 |
| 观战（spectate） | **没有真人座位**，4 个 PC 全是模型 | 只读观战，隐藏输入框/技能栏 | 同上 |

**关键区别**：托管是"你的座位还在，只是先由 AI 答"；观战是"这桌没有你"。
所以观战局点「接管」会明确拒绝（没有座位可接）。

**节奏**：自动模式每轮结束歇 **1.2 秒**（`WebSession.pace`），否则假模型一局不到
1 秒就跑完，页面只剩结算。它只是展示节奏，不参与规则、不进存档。

## 2. 怎么开

1. 起服务：`python -m engine.demo_web --port 8801`（假模型，零花费；默认端口是 8770，这里用 8801 示例）；
   真模型：加 `--real --max-calls 40`（整局上限，到了就拒绝发请求）；
2. 浏览器打开 `http://127.0.0.1:8801/`；
3. 顶栏「真人 / 托管 / 观战」选一个 → 点「按此模式新开」（会丢当前进度）；
4. 托管中随时可点横幅右侧「接管」，下一轮就等你输入。

**服务现在不会跑完就关**：一局结束会打结算，但网页还开着，可以继续「按此模式新开」。
`--auto`（自带假浏览器）仍是**跑完即退出**的一次性进程，给回归用。

## 3. 实现（文件 / 入口）

| 位置 | 作用 |
|---|---|
| `engine/webui.py` `WebHumanSeat` | 接受 `auto` 回调：有它就是托管，没有就等网页 |
| `engine/webui.py` `WebBridge.snapshot` | 多返回一个 `mode`，前端据此切换 |
| `engine/demo_web.py` `make_web_table(mode=…)` | 观战换掉真人座位；托管给真人座位装 pilot |
| `engine/demo_web.py` `_auto_option` / `_pilot_callable` | 假模型兜底 / 真模型把 JSON 意图翻成座位输入 |
| `engine/demo_web.py` `WebSession.set_hosted` | 只换"谁在答"，不重建这一局 |
| `engine/rules/loop.py` `GameLoop.on_round` | 每轮结束回调（观战节奏）；抛错只记问题、不崩局 |
| `engine/demo_web.py` 主循环 | 一局结束打结算但**不关服务**；页面可再开 |

**座位纪律没变**：观战只是把 `players[human]` 换成模型座位；托管只是给
`HumanSeat` 一个 `auto` 回调。`GameLoop`、菜单、装配器、台账一行没改。

## 4. BGM

- **纯浏览器合成**：`AudioContext` 两个振荡器 + 慢速 LFO，**不加载任何 mp3/外链**；
- 情绪：探索 = 110/164.8Hz 慢呼吸；战斗 = 55/82.4Hz 锯齿 + 2Hz 起伏（看 `map.battle`）；
- 顶栏「BGM」开关；设置页有音量滑杆；`localStorage` 记住开关与音量；
- 浏览器自动播放策略：刷新后如果上次是开着的，**等你第一次点页面**才起声。

**限制**：这是一段环境音，不是配乐；没有曲目切换、淡入淡出、场景专属 theme。
要"进酒馆换曲"得后面接音频文件与授权素材，别把现在这版说成"有配乐"。

## 5. 兼容与边界

- `new_game` 不传 `mode` 仍是 `normal`（旧页面/旧脚本不受影响）；
- `mode` **不进存档**：读档按当前页面选中的模式继续（服务端保持 `self.mode`）；
- 切模式会 `_stop_old()`（等旧线程最多 3 秒），所以点完按钮到横幅更新可能慢 2~3 秒，
  这是等旧一局收尾，不是卡死；
- 新开一局会清掉**显示日志**（序号继续递增，前端 `since` 不会错位）；
- 托管/观战不改变规则与记账：调用照样进 `client.calls` 与复盘。

## 6. 验证

- `tests/t_modes.py` **34 项**：兜底选动作、观战自动跑完、观战无真人座位、
  托管 auto 开关、接管后等人、观战不能接管、`on_round` 抛错不崩、页面静态接线；
- `tools/web_modes_check.py`（Edge/Playwright）：BGM 开关、观战横幅+隐藏输入、
  托管+接管后输入框回来、模式选择同步；截图在 `真模型记录记录`。
- 真模型观战/托管**还没跑过**（Q39）：假模型只证明链路，不证明真模型会选得好看。

## 8. 已知限制

1. 托管「接管」只在**下一轮**生效；当前正在生成的这一答不会撤回。
2. 观战局不能中途接管（没有真人座位）；要玩就新开一局「真人」。
3. 假模型观战是**确定性策略**（挑第一个合法项），只适合流程测试，不代表 AI 打得好。
4. BGM 只在无头浏览器里验了"能起、能关、状态对"，**没有验人耳听感**。
5. 真模型托管/观战的花费：`--max-calls` 是整局硬闸，不是按模式区分。
