## 1. 四条铁律

| # | 铁律 | 落地 | 守卫 |
|---|---|---|---|
| 1 | **骰子和判定永远由代码做** | `Unit.take_damage()` 等是数值改动唯一入口 | `check_isolation` / `t_unit` |
| 2 | **提示词静态在前、动态在后**；静态一字节不许每轮变 | `state/assembler.py` 的 `BLOCK_ORDER` | `t_assembler` E1/E2 |
| 3 | **每个单位的上下文只能由装配器产出** | `Assembler.build()` 唯一出口；台账块不许手塞 | `t_assembler` I1 / `verify_isolation` |
| 4 | **所有真模型调用走同一个出口** | `ModelClient.complete()`；子类只实现 `_complete()` | `t_loop` G5；默认 `enabled=False` |

> 历史教训：**“自称离线的测试一直在真花钱”**——记忆不是证据；出口闸 + 默认关才是。

**抽不到就明说**：半结构化字段抽不到就 `structured=False` + 原因，界面标"需 DM 裁定"，不静默按错规则打。

## 2. 状态树与可见性

### 2.1 `stat_data` 树

```
角色列表.<角色名>.职业 / 档案与个性 / 属性 / 生命值 / 护甲等级 / 先攻 / 速度 / 当前状态
角色列表.<角色名>.熟练配置        {技能, 豁免, 武器, 护甲, 工具}
角色列表.<角色名>.资源.<名>       {当前值, 最大值, 恢复规则}
角色列表.<角色名>.物品.<名>       {类别, 已装备, 装备栏, 攻击加值, 伤害骰, 护甲加值, …}
角色列表.<角色名>.特性.<来源>.<名> {描述, 来源}
角色列表.<角色名>.施法.法术位.<环阶>   {当前, 最大}
角色列表.<角色名>.施法.法术书.<法术名> {等级, 准备中, 学派, 成分, 描述}
当前角色ID
```

- 结构照抄 MVU，但**谁算数换了**：模型出意图 → 代码算 → 代码写 patch；
- `delta` 只写增量，只能改数字；
- `commit()` 强制 `actor` + `reason`，每次改动自动审计。

### 2.2 可见性四档

| `visible_to` | 谁能看 |
|---|---|
| `public` | 全场 |
| `dm` | 只有 DM |
| `pc:<名字>` | 这个人 + DM |
| `engine` | 只有引擎/复盘（暗骰明细，连 DM 都不给） |

- **DM 看得到全部私有信息**（主持人），但**不许把角色没说出口的私有信息复述进旁白**；
- 不外泄靠提示词约束 + `lint_leaks()` 兜底，不是靠“不给 DM 看”；
- 记忆块只能由 `memory_provider(viewer)` 现渲染，`set_block("记忆")` 直接报错。

### 2.3 事务边界

- `StateTree.transaction()` **只回滚状态树**；台账、记忆库、战斗内存 Unit（敌方 HP）、RNG **不在回滚范围**；
- 网页动作 `apply_action` 是一笔事务；失败后 `_resync_pc_units` 把 PC 的 hp/ac 拉回状态树；
- 纯校验失败不刷审计；真回滚记一条 `patch=[]` 审计；
- 战斗轮/多意图回合**未包事务**，当前粒度是“一个网页动作”。

### 2.4 防全知

- **不信装配器的自述**：`Assembler` 报的 included/excluded 只当参考；
  `verify_isolation` 抓**真实发出的提示词**，按“谁该看到”逐个查；
- **双向检查**：不该看到却看到 = 泄漏；该看到却没看到 = 覆盖缺口；
- **守卫要能自证有效**：故意造一次公开泄漏，`lint_leaks` 必须抓到；抓不到说明守卫失效。

## 3. 规则结算

### 3.1 骰子与菜单

- 骰子唯一出口：`engine/dice/roller.py`；全项目只有这里 `import random`；
- 合法动作菜单：`rules/menu.py`；模型**只能从菜单里挑**，不能发明动作；
- 攻击/豁免/伤害/AoE/施法：`rules/adjudicate.py`；
- 战斗单位：`rules/unit.py`；回合：`rules/turn.py`；编排：`rules/loop.py`。

### 3.2 法术

1. **一个可用环阶一条选项**：只列引擎算得出数值收益的升环；算不出的升环不列；
2. **AoE 不让模型选落点**：菜单列“射程内全部候选”，选中就结算全部候选（第一版简化，不是几何）；
3. **施法属性按职业取**；触碰法术按 5 尺算目标；中文法术名走 `_SPELL_CN` 映射，找不到**明说**；
4. 法术位由引擎扣；反应法术不进菜单，只在触发条件满足时执行。

### 3.3 反应 / Ready

- 反应不是可选行动；第一版触发只有 `enters_reach` 与 `attacked`；
- 一次反应只干一件事；Ready 寿命到下个回合开始，`reset_turn()` 清空；
- 护盾术只翻掉触发它的那一次命中，不保留持续 +5 AC。

### 3.4 传奇 / 巢穴

- 传奇动作只在**别人回合结束时**插入，按 `legendary_cost` 扣点，自己回合开始刷新；
- 巢穴动作只在**先攻 20** 触发，每轮一次，`reset_round()` 刷新；
- 由本地策略挑，不调模型；够不着/点数不够就**不用也不扣**；纯描述型照常扣点并标“需 DM 裁定”。

### 3.5 护甲 / 装备

- 护甲 AC 在 `rules/armor.py`：无甲/轻/中/重/盾公式；
- **8 格**：头盔 / 上装 / 下装 / 靴子 / 左手 / 右手 / 饰品1 / 饰品2；
- 盾牌锁左手；有盾禁双手；双手占左右手两格；战斗饰品最多 2 件；
- 日常服装/饰品不占战斗栏、不参与 AC/攻击；
- 换同栏护甲自动卸旧甲；手部不自动抢；旧物品按类别/名字推断栏位（兼容，不是新规则）；
- 网页换装走 `web_actions.equip_item` → `commit` + 审计；战斗中拒绝。

### 3.6 规则文本

- 只从本地 SRD `rules` 原文摘录，不改写、不补规则；找不到就写“找不到规则「X」”；
- 按探索/战斗/施法/社交分组；默认 1700 字预算，装不下写明“还有 N 条未收入”；
- 结果确定性缓存，同场景同预算给同一段文本。

### 3.7 输出体检

- 解析器尽力消费；体检器只判 `valid / invalid / truncated / refusal / error`，**不替解析器猜**；
- 只有“完整但非法”纠错一次；截断/拒答/传输错误原样返回；
- 真人座位不自动纠错；纠错请求算一次真实调用，记账可见 `任务_repair`。

## 4. 剧本 / 世界 / 记忆

### 4.1 世界

- “未知”就是不渲染：没发现的地点、没听说的派系、不公开的任务，**根本不进玩家视角**；
- 秘密只给 DM；世界也走 `commit()`（发现地点、换地点、改态度、推任务、推时间都有审计）。

### 4.2 线索

- 只有玩家选「观察 / 搜索」才掷；失败句与“有没有线索”无关；
- **没有线索也照样掷一次骰**，否则“有没有公开结果”本身就是提示；
- 公开句只写“做了什么”；结果只给行动者（和 DM）；骰面明细不进台账；
- 同一个人对同一条只能试一次；换场允许一次；发现状态写世界树，读档不重置。

### 4.3 被动察觉

- 被动值 = `10 + 察觉总加值`，与主动检定同一份加值；
- 只查 `perception`；调查类痕迹必须主动搜索；
- 一条痕迹只交给被动值最高的人，秘密只进他的私有台账。

### 4.4 时间召回

- **先按内容挑，再按时间分组**；排序键 `(-分数, 登记顺序)`，**没有时间项**；
- 时间是游戏内时钟（剧本日期+时段，退回世界树），不是墙上时间；算不出就写“记不清时间”；
- 记忆块与台账同纪律：按视角现渲染，不能手塞；
- 词法 IDF + 别名表；`TEXT_CAP=2`，结构化证据分不变。

### 4.5 长跑 / 上下文

- 存储全、渲染挑：台账只给最近 N 轮（探索 6 / 战斗 4）；折叠首行写明“更早 N 条已折叠”；
- **先按视角过滤、再截断**，顺序不许反；
- 预算 `TRIM_ORDER = 记忆 → 世界 → 队友 → 规则`；角色卡/菜单/任务/台账**永不裁**；
- 裁了必须留痕：`Assembled.dropped` / `over_budget`；默认不裁。

### 4.6 剧本 / 战役 / 任务日志

- 剧本 `adventures/*.json` 是唯一真相；`*.progress.json` 是玩出来的记忆，跑过才有；
- 进度是状态的一部分：`story_act/story_scene/story_status/scenes_done` 随档往返；
- 读档从“当前场景开头”继续（半场存档会重跑本场，不假装精确到回合）；
- 任务 = 剧本场景；任务日志只列当前场 + 已完成场，未跑场不剧透；
- **跨章欠账**（`campaign.json`）：上一章 open 的伏笔汇总成欠账块，只在**这本剧本的第一场**注入 DM 任务说明；
  同一存档续跑也注入（不是“只在全新一局”）；欠账只读不写，本章收不掉上一章的伏笔（Q23）；
- **单场简报**（`brief.present/span/offstage`）与未发现线索只拼进 **DM 的任务说明**（`dm_hint`）；
  PC/planner 包里没有 —— `t_brief_isolation` 真跑剧本抓包断言，变异 M103 守门；
- 回执只记事实：完成、已发现线索、`pays` 收掉的伏笔；**没有金币/经验奖励表**。

### 4.7 回到某一场

- 只认“前面都跑完”：从 s2 开始前先检查 s1 已完成，否则报错；
- 运行态可退、历史不退：`scenes_done` 重算，进度文件里的 beat/已兑现不删不改；
- 重跑期间不塞跨局欠账；重跑不重复记 beat。

## 5. 网页 / 存档 / DM 造物

### 5.1 网页座位

- 只绑 `127.0.0.1`；没有鉴权就不暴露局域网/公网；
- 只换输入方式，不碰引擎：`WebHumanSeat` 只重写 `_answer()`；
- 零依赖、轮询不 WebSocket；不合法动作返回 `ActionError`，不假装成功；
- 前端工具入口与浮层数会随功能增减（当前 11 / 15）；**别把数字当契约**，开桌只是前端仪式，不改引擎状态。

### 5.2 存档

- 默认 `FakeModel`；真模型必须显式传且 `enabled=True`；
- 版本不对就拒绝（`format` + `version`）；v4 读 v3 旧档（新字段按缺省），更老明确拒绝；原子写盘；RNG 状态一起存；
- 3 个固定槽 + 最近存档；槽号只认 1~3；每槽完整存档，互不覆盖；
- 导出/导入；读档续跑当前剧本进度；换局先 `abort` 旧线程。
- 留痕：存档内含 `audit` + 台账；同目录追加 `save_log.jsonl`（时间/场景/条数/sha256），覆盖前旧档进 `history/`；
- **留痕有容量预算**（ADR-118）：`history/` 20 份 / 64 MB 双阈值（取更严，至少留最新一份），
  `save_log.jsonl` 超 4 MB 裁最旧；trace 同理（keep=10 / 256 MB）；`saves/mock` 与 `saves/real` 分开。

### 5.3 DM 造物

- 世界书只给框架；DM 可补描述/机制/数值/效果/背景；
- **只有结构化字段进引擎**：`攻击加值`（总命中，不再叠熟练/属性）、`伤害骰`、`伤害类型`、
  `护甲加值`、`护甲类型`、`双手`；
- 文字与数值分开：`物品志/法术志/技能志` 是说明文字，不进骰子/AC；
- 当局边界：DM 造物跟存档，新开一局清空，不写世界书；
- **已接**：自定义动作/技能（attack/save/heal/范围伤害，`rules/homebrew.py`）；DM 人物数值块（AC/生命/属性/豁免熟练/技能加值/先攻/攻击 → `rules/npc_units.py`，战斗中可作为敌人/盟友上场并进先攻序）；临时修正（AC/攻击/豁免/技能/检定/伤害，场景/轮次到期，`rules/effects.py`）；装备词条（免死/临时生命/回合回复/常驻属性，品级 1~4 + 每人预算，`rules/effect_catalog.py`、`rules/item_effects.py`）；
- 当前入口是网页表单/HTTP action，不是“听口述自动落库”；字段定义在
  `engine/web_actions.py` 的 `_ITEM_STAT_KEYS`（不要再去 `state/schema.py` 找）。

### 5.4 schema / 体验层

- **schema 只挡“写坏”**：类型/范围/结构校验，失败整体回滚；未知字段放行，缺字段不补默认（模板负责）；
- 读档从“当前场景开头”继续；半场存档会重跑本场，不假装精确到回合；
- 开桌是前端仪式，不改引擎状态；血量叙事按引擎 HP（>50% 写体力/运气，≤50% 才见血，0 HP 才倒地）；
- 先攻条只读快照；没战斗就隐藏，不伪造。

### 5.5 网页附加面板（自检 / 复盘 / 思考提示）

- **自检** `GET /api/diag`：只读；key 只回答"有没有"、绝不返回内容；目录可写性用"真写临时文件再删"判定。
- **复盘** `/api/games`、`?lite=1`（只给 token/耗时 + `reasoning_len`）、`/api/game/call/<i>`（全文，标 `spoiler`）。
  名字只认单段 `.json` + 目录内（`review.resolve`），穿越 404；**全文含剧透，不发玩家座位**。
- **思考提示** `on_call(actor,task,phase)` + `/api/state.thinking`；开关存 `localStorage['dnd_show_think']`，
  关掉连"谁在想"都不显示；钩子异常记 `hook_errors`（不静默吞）。
- ⚠️ 前端防回归：`poll` 必须 `async`；`applyThink` 只在 `poll` 调一次（坑 25/26 见 12 §4）。
- 审核/拒答：`format_check` 分出 `moderation`；叙事层重述一次、仍拒留白，`refused` 进留痕（见 48）。

## 7. 修改前的最低检查

1. **改规则/数值**：先读本文件 §3；改完跑 `python tests\run_all.py`；
2. **改状态/可见性/装配**：读 §2；跑 `check_isolation` + `t_assembler`；
3. **改模型接线**：确认默认 `enabled=False`、出口闸、记账；
4. **改网页动作**：走 `commit`、失败回滚、战斗中拒绝；
5. **改行为**：配一次变异验证（把修复改回旧写法，确认测试变红；做法见 `tests/check_mutation.py`）；
6. **改文档数字**：跑 `check_docs`，数字只认 `_last_report.json`；
7. **不确定就明说**：抽不到结构化字段就 `structured=False`，让界面标“需 DM 裁定”。

**代码卫生**：新修复配变异验证（守卫要能证明自己会红）；只吞 `NotFound`，数据损坏/解析失败必抛；
配置只认正确类型；动作经济再校验覆盖所有分支；文档数字要能被 `check_docs` 复算（细节见旧 §4.15）。
