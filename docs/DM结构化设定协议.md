# DM 结构化设定协议 v1（2026-11-06）

> 世界书只给框架和部分明确内容；其余人物/物品/事件由 DM 按当局补。
> **文字归 DM，数值归引擎**：能进加减乘除的必须是结构化字段；纯文字只作说明。
> 所有写入都只进**当前这一局**（`StateTree` + 存档），新开一局不保留，不入世界书。

## 1. 物品（已接引擎）

物品是 `角色列表/<角色>/物品/<名称>` 下的对象。DM 造物走
`dm_create_item`，改数值走 `set_item_stats`。

| 字段 | 类型 | 说明 |
|---|---|---|
| `类别` | 文本 | 武器 / 护甲 / 盾牌 / 饰品 / 日常服装 / 消耗品 / 物品 |
| `装备类型` | 文本 | `战斗` 或 `日常`；日常不占战斗栏、不参与数值 |
| `装备栏` | 文本 | 8 个战斗栏之一；由装备动作写入，不手填；引擎校验 |
| `攻击加值` | 整数 | **命中总加值**；引擎不再叠加熟练/属性；已进引擎 |
| `伤害骰` | 文本 | 如 `2d6+5`；引擎按骰式结算；已进引擎 |
| `伤害类型` | 文本 | 挥砍/穿刺/火焰…；映射到引擎伤害类型 |
| `护甲加值` | 整数 | 基础 AC；护甲/盾牌/饰品可用；已进引擎 |
| `护甲类型` | 文本 | 轻甲/中甲/重甲/盾牌；已进引擎 |
| `武器特性` | 数组 | 如 `["灵巧"]`、`["双手"]`；部分进引擎 |
| `射程` / `触及` | 整数 | 尺 |
| `来源` | 文本 | DM 造物为 `DM`（只作标记，不参与计算） |

> 字段定义在 `engine/web_actions.py` 的 `_ITEM_STAT_KEYS`；不在 `engine/state/schema.py`。

**不进引擎的**：`描述`、`机制`、`数值`、`效果`、`背景` 存在
`世界/物品志/<名称>`，卡片展示，不参与骰子/AC。

## 2. 装备栏（已接引擎）

战斗装备固定 8 格：

```
头盔  上装  下装  靴子  左手  右手  饰品1  饰品2
```

规则：

1. 一格最多一件战斗装备；
2. 盾牌固定占**左手**；有盾牌时禁止双手武器；
3. 双手武器占**左右手两格**，不能和盾牌/另一把武器同时用；
4. 战斗饰品最多 **2 件**；只算战斗饰品，日常饰品不占；
5. 日常服装/饰品不占战斗栏、不限数量；不参与 AC/攻击；
6. 换同栏护甲自动卸旧甲；手部不自动抢，避免顶掉武器。

## 3. 动作 / 技能（已接引擎，2026-11-07）

存在 `角色列表/<角色>/动作/<名称>`；网页「状态 → DM 技能」写入，战斗中也能造。
**只有下表字段进引擎**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `类型` | 文本 | `attack` / `save` / `heal` / `utility`（也认 攻击/豁免/治疗/描述） |
| `动作槽` | 文本 | `action`（默认）或 `bonus_action` |
| `攻击加值` | 整数 | 命中**总加值**；不填按力量/敏捷 + 熟练算（attack） |
| `伤害骰` | 文本 | 如 `2d6+4`；attack 必填，save 可选 |
| `伤害类型` | 文本 | 挥砍/火焰…；映射到引擎伤害类型 |
| `豁免` | 文本 | 力量/敏捷/体质/智力/感知/魅力（save 必填） |
| `DC` | 整数 | 1..40（save 必填） |
| `半伤` | 开关 | 豁免成功是否半伤（save） |
| `范围` / `范围形状` | 整数 / 文本 | 尺 / cone·sphere·cube·line·emanation（save） |
| `射程` | 整数 | attack：≥10 尺按远程；heal：治疗距离（默认 5） |
| `治疗骰` | 文本 | 如 `2d4+2`（heal 必填） |
| `次数` | 整数 | 每日次数，0 = 不限 |
| `描述` | 文本 | 动作怎么做；进菜单给模型读，**不是**规则 |

- `来源=DM` 只作标记；
- 类型与字段错配（如攻击型填 `范围` / `治疗骰`）在写入口**直接报错**，不静默丢弃；
- 控制/召唤/变形/持续轮数等附加效果**不自动结算**，仍交 DM 裁定；
- 实现：`engine/rules/homebrew.py`（写入口严格校验 + 读入口宽容降级）；
- `动作`（引擎状态）和 `技能志`（说明文字）是两回事，后者只做卡面。

## 4. 人物（已接引擎，2026-11-07 / H2a）

存在 `世界.角色/<名>/数值`；网页「人物」面板写入，DM 可对**已登记**的人物写数值。
**只有下表字段进引擎**，人格/状态/身份仍只做叙事：

| 字段 | 类型 | 说明 |
|---|---|---|
| `生命值` | 整数 | **必填**；1..1000，上场时满血 |
| `护甲等级` | 整数 | 1..40，默认 10 |
| `等级` | 整数 | 1..20，默认 1（决定熟练加值） |
| `属性` | 对象 | 六项属性（力量/敏捷/…），1..30；引擎算调整值 |
| `豁免熟练` | 数组 | 如 `["敏捷","体质"]`；引擎加熟练加值 |
| `技能加值` | 对象 | 技能 → **总加值**（如 `{"察觉": 4}`）；被动察觉 = 10 + 察觉 |
| `先攻加值` | 整数 | **总值**，覆盖敏捷调整值（-10..20） |
| `速度` | 整数 | 尺，默认 30 |
| `动作` | 对象 | 动作名 → 与 §3 同格式的技能（attack/save/heal） |

- 人物**没有数值块就不能上场**（`dm_add_npc_to_combat` 报错，不偷偷给通用怪）；
- 只能在**战斗中**放上场；同名人物一场只能在场一次；
- 战斗中加入按它的先攻**插进当前先攻序**，不是排最后；
- 已在场上的单位改数值**本场不重算**（下一场生效），避免战斗中偷偷改命；
- 事件临时修正（“高地 +1 攻击”“毒雾劣势”）见 §5。

## 5. 临时修正（已接引擎，2026-11-07 / H2b）

挂在单位身上的**临时加值**，到期自动掉；不改基础 AC/属性。

```json
{
  "name": "坡顶视野",
  "kind": "attack",
  "value": 1,
  "target": "party",
  "scope": "scene"
}
```

| 字段 | 说明 |
|---|---|
| `name` | 显示名（≤40 字） |
| `kind` | `ac` / `attack` / `save` / `skill` / `check` / `damage` |
| `value` | 加值，-20..20 |
| `object` | `save`/`check` 用属性（力量…）；`skill` 用技能（察觉…） |
| `scope` | `scene`（换场清掉）或 `round`（自己回合开始扣 1） |
| `rounds` | `scope=round` 时必填，1..20 |
| `target` | **只有剧本效果用**：`party` / `enemy` / `all` |

- **剧本**：写在 `scenes[].effects`；进场景挂队伍，开战时给敌人补挂；
- **网页**：`dm_apply_effect`（带 `target`：全队/敌人/全场/某人）与 `dm_clear_effects`；
- 同名同来源只保留一条（不叠层）；`round` 档在**该单位自己回合开始**扣；
- 只改引擎判定，不改基础数值：`Unit.ac` 仍是基础，`Unit.ac_total` 才是有效值；
- 夹具（原创、只测效果）：`tests/fixtures/effects_scout.json`。

> 不做：基础属性改写、叠层、跨场景的长期 buff 表；需要这些另开协议。

## 6. 词条库与自写词条（已接引擎，2026-11-07 / H3）

**原则**：DM 不手填效果，只能挑词条；词条是**封闭词汇**，写不进库的效果引擎不认。

### 6.1 载体

| 载体 | 字段 | 适用词条 |
|---|---|---|
| 装备 | `角色列表.<角色>.物品.<名>.词条 = ["ward_grace"]` | `适用=装备/通用` |
| 生物 | `世界.角色.<名>.词条 = ["swift_10"]` | `适用=生物/通用` |
| 本战役自写 | `世界.词条库.<id>`（跟存档，新开一局清空） | 由 DM 指定，仍受词汇限制 |

### 6.2 内置词条（摘要）

| id | 名称 | 品级 | 适用 | 效果 |
|---|---|---|---|---|
| `guard_1` / `guard_2` | 轻甲片 / 守御纹 | 1 / 2 | 通用 / 装备 | 常驻 AC +1 / +2 |
| `aim_1` | 鹰眼 | 2 | 装备 | 常驻攻击 +1 |
| `steady_1` | 定神 | 2 | 装备 | 常驻豁免 +1 |
| `vigor_minor` / `vigor_major` | 战前鼓舞 / 不落之旗 | 1 / 2 | 装备 | 开战临时生命 3 / 6 |
| `moss_minor` / `moss_major` | 苔藓再生 / 常青之心 | 2 / 3 | 装备 | 回合开始回复 1 / 3（冷却 1 / 2） |
| `ward_minor` | 余荫（次） | 3 | 装备 | 每场一次免死，保留 1 点 |
| `ward_grace` | 生命之神的余荫 | 4 | 装备 | 每场一次免死 + 回复 8 |
| `swift_10` | 千里之足 | 2 | 生物 | 速度 +10 尺 |
| `tough_8` | 厚皮 | 2 | 生物 | 生命上限 +8 |

品级：1 常见 / 2 精良 / 3 稀有 / 4 传说。

### 6.3 预算（防“乱发神装”）

- 一件装备最多 **3 条**，品级合计 **≤6**；
- 角色已装备（非日常）词条合计 **≤ 2 + 等级**（最低 3）；超了 `equip_item` 直接拒；
- 生物词条不计入角色预算（NPC 由 DM 负责平衡）；
- 品级不是自称：`validate_entry` 按效果兜底最低品级（免死 ≥3，带回复 ≥4；临时生命 >6 要 ≥3；回复 ≥3 点要 ≥3）。

### 6.4 DM 自写（只在本战役）

```json
{"kind":"dm_create_entry","id":"x_life_blessing","名称":"圣徽余晖",
 "品级":3,"适用":"装备","触发":"致命伤害","效果":"免死",
 "数值":0,"保留生命":1,"每场":1,"说明":"本战役的教会圣物。"}
```

- `id` 必须小写字母/数字/`_`，2~40 字，不能撞内置 id；
- 只能写引擎已接的词汇：`常驻` + `ac/attack/save/speed/hp`，或
  `战斗开始→临时生命`、`回合开始→回复`、`致命伤害→免死`；
- 写坏/低于品级下限 → HTTP 400 + 明确原因，不落库；
- 网页入口：造物表单里「词条库 / 写新词条」；写好的词条立刻出现在物品/人物下拉里。

### 6.5 明确不支持

- 条件触发（“对亡灵额外伤害”“半血以下才生效”）、光环、叠层、改骰、召唤；
- 经济类（“金砖的珍贵”→ 售价/估价）：引擎没有物品估值钩子，先别写成词条；
- 跨场景永久成长（词条是装备期间/每场重置的）。

## 7. 审计与回滚

所有写入走 `StateTree.commit`：

- actor=`DM`（造物/改数值）或 `玩家:<角色>`（装备）；
- 失败走事务回滚，不留半截；
- 存档/读档保留；新开一局新 `StateTree`，不写 `adventure.json` / 世界书。
